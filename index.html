What the system did by itself

Every automatic action is logged here, so the committee can see it working.

    Payment inbox

    Zelle and Cash App send an email for every payment. The system reads each one, matches it to a household and marks them paid. In the live version this runs by itself every 5 minutes.

    Tap the button to see the system read the next payment email.
